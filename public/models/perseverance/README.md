# Perseverance rover model

This work is based on "Perseverance Mars rover" (https://sketchfab.com/3d-models/perseverance-mars-rover-53034dff0df04f698f2a5d532366adc4) by Cybertron B-127 (https://sketchfab.com/robo-reboot), licensed under CC-BY-4.0 (http://creativecommons.org/licenses/by/4.0/).

Changes: textures above 512 px were halved and recompressed for the web. Geometry is unchanged. At load time the Mars page splits the combined wheel meshes into six spinning wheels and merges static parts by material (components/planets/mars/rover.ts).

The original license file is kept beside this README as `license.txt`.
