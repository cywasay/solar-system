# Uranus imagery

- `webb.png`: NASA / ESA / CSA / STScI, Webb NIRCam, September 4, 2023. Infrared composite with assigned visible colors; not natural-color photography. Downloaded at 1600 × 1156.
  - Source: https://science.nasa.gov/missions/webb/nasas-webb-rings-in-holidays-with-ringed-planet-uranus/
  - Asset: https://assets.science.nasa.gov/dynamicimage/assets/science/missions/webb/science/2023/12/STScI-01HHFP5G5BXSC5M7DX6DG9YXMB.png?fit=clip&w=1600
- `miranda.jpg`: NASA / JPL, PIA00042, Voyager 2, January 24, 1986. Green/violet/ultraviolet filter composite. Resampled download 800 × 1046; source resolution is lower. No additional scientific detail is implied by the resampling.
  - Source: https://science.nasa.gov/photojournal/miranda-highest-resolution-color-picture/
  - Asset: https://assets.science.nasa.gov/dynamicimage/assets/science/psd/photojournal/pia/pia00/pia00042/PIA00042.jpg?fit=clip&w=800
