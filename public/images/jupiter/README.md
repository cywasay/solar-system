# Jupiter image sources

- `cloud-map.jpg`: NASA / JPL / Space Science Institute, [PIA07782](https://science.nasa.gov/photojournal/cassinis-best-maps-of-jupiter-cylindrical-map/). Cassini composite, December 2000. The page crops and translates horizontal pieces for a conceptual motion study; their displacement is not measured wind.
- `red-spot.jpg`: NASA / JPL-Caltech / SwRI / MSSS, processing by Kevin M. Gill (CC BY), [PIA23606](https://science.nasa.gov/photojournal/the-great-red-spot/). Processed JunoCam visible-light image. The animated fold is illustrative. The adjacent depth diagram uses separately sourced estimates.
- `galilean.jpg`: NASA / JPL / DLR, [PIA01299](https://science.nasa.gov/photojournal/the-galilean-satellites/). Galileo images of Io, Europa, Ganymede and Callisto at common image scale, montage spacing.

The files are width-limited derivatives from NASA Science's image service. No generative images or recolored scientific textures are used.
