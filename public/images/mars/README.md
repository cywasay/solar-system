# Mars imagery provenance

`valles-marineris.jpg` is a 2400px derivative of NASA Photojournal PIA00422.
Credit: NASA / JPL / USGS. Viking Orbiter mosaic combining monochrome and color imagery, Mercator projection. No MRO or ESA imagery is used in this asset.

Source: https://science.nasa.gov/photojournal/valles-marineris/
Downloaded from: https://assets.science.nasa.gov/dynamicimage/assets/science/psd/photojournal/pia/pia00/pia00422/PIA00422.jpg?fit=clip&w=2400

The hero uses decorative cropped slices with an edge gradient. The article displays the same mosaic as a contextual image. No generated imagery is presented as observation.

The cutaway and linework are authored illustrations. They are not measured terrain or MOLA data. The previous hand-entered elevation profiles have been removed from the page.
