# Neptune imagery

- `voyager.jpg`: NASA / JPL, PIA00046, Voyager 2, August 1989. Enhanced to reveal small atmospheric features at the expense of color fidelity, as stated by the original caption. Download 1000 × 1000. The page explicitly labels the enhancement and explains the 2024 visible-color reassessment.
  - Source: https://science.nasa.gov/photojournal/neptune-full-disk/
  - Asset: https://assets.science.nasa.gov/dynamicimage/assets/science/psd/photojournal/pia/pia00/pia00046/PIA00046.jpg?fit=clip&w=1000
- `triton.jpg`: NASA / JPL / USGS, PIA00317, Voyager 2, 1989. Synthesized color combines orange, violet, and ultraviolet filter images. Download 1400 × 1088.
  - Source: https://science.nasa.gov/photojournal/global-color-mosaic-of-triton/
  - Asset: https://assets.science.nasa.gov/dynamicimage/assets/science/psd/photojournal/pia/pia00/pia00317/PIA00317.jpg?fit=clip&w=1400

The discovery plate is conceptual, not historical astrometry. Wind paths are an illustrative motion treatment, not a measured velocity field. The dark-blue interface is art direction, not a natural-color reference. Photographs are not recolored to match it.
