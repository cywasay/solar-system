# Venus imagery

- `magellan-globe.jpg`: NASA/JPL, [Computer-simulated Global View of Venus](https://svs.gsfc.nasa.gov/30357), downloaded 8 November 2026 from the 1024 px print asset. Magellan first-cycle radar mosaics projected onto a simulated globe, centered at 180 degrees east. Gaps filled with Pioneer Venus data or a constant value. Simulated colors are based on Venera 13/14 imagery. CSS crops the surrounding black margin; the source file is unchanged.
- Cloud texture reused from `public/textures/2k_venus_atmosphere.jpg`, Solar System Scope, CC BY 4.0. The page identifies its projection as illustrative. It is not registered to the radar view.

Scientific references are linked beside the corresponding sections. Rotation, orbit, and solar-day periods are kept distinct. The atmosphere values follow NASA's Venus overview; rounded published temperatures and pressures vary between reference datasets.
